# Dragon Ball Z: Budokai Tenkaichi 3 Tag Team PC Recomp — Community Fixes & Mods

## 📖 About This Repository

Welcome to this community-driven repository dedicated to fixes, improvements, and optional modifications for Dragon Ball Z: Budokai Tenkaichi 3 Tag Team PC Recomp.

The purpose of this project is to improve the gameplay experience, address technical issues, and introduce additional features while preserving the original game's identity.

All modifications are intended to be optional, allowing players to enjoy either the original experience or an enhanced version according to their preferences.

Tested only with English/USA BT4 B14 REV2; spanish version expected to be compatible but not tested.

## 🤖 Development & AI Assistance

This project is developed with the assistance of OpenAI's Codex, using GPT-6.1 Sol and other available AI models.

AI-assisted development is used for:

- Source code analysis and reverse engineering.
- Identifying and correcting gameplay issues.
- Implementing new gameplay mechanics.
- Improving compatibility and performance.
- Testing and validating modifications.
- Developing optional quality-of-life improvements.

Development is guided by human decisions, gameplay observations, technical experimentation, and practical testing.

AI assistance is a development tool, not a substitute for testing and validation.

## 🛠️ Fixes & Improvements

This repository aims to provide community fixes for issues encountered in the PC recompilation.

These may include:

- Gameplay and combat-related corrections.
- Special attack and camera behavior improvements.
- Visual effect adjustments.
- Compatibility fixes.
- Optional gameplay enhancements.

Each modification will be documented individually, including its purpose, compatibility requirements, and installation instructions.

## 🎮 Optional Gameplay Mods

Beyond technical fixes, this repository may also introduce optional gameplay modifications inspired by other Dragon Ball fighting games.

The objective is to explore new possibilities while keeping the original gameplay accessible.

Players should always have the freedom to enable or disable modifications according to their preferences.
